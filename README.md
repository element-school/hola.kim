# hola.kim

Kim González-Chang's portfolio site. Plain HTML and CSS, no build step, served by GitHub Pages from `main`.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Files

- `index.html`: the page
- `styles.css`: styles (light and dark mode)
- `assets/`: photos and work samples
